# 重要通知ポップアップ（園長・担当者向け）

本部が Google スプレッドシートに書いたお知らせを、指定した先生の Chrome に、指定した日時・頻度でポップアップ表示する仕組みです。

## 仕組み

```
本部                              各園の先生のChrome
┌───────────────────────┐        ┌──────────────────────────┐
│ Googleスプレッドシート │        │ Chrome拡張機能            │
│  ├ 通知（内容・対象・日時）│ ◀───── │  ・5分ごとに通知を取得    │
│  ├ 宛先マスタ（先生⇔園）  │  HTTPS │  ・時刻が来たらポップアップ│
│  └ 確認ログ（自動記録）  │ ◀───── │  ・「確認しました」を送信  │
│ ＋ Apps Script（ウェブアプリ）│    └──────────────────────────┘
└───────────────────────┘          ▲ Google管理コンソールから一括配布
```

- **サーバー不要**：お客様の Google Workspace 内のスプレッドシートと Apps Script だけで動きます。開発者のPC・外部サービスには依存しません。
- **本部の管理画面＝スプレッドシート**：行を追加すれば配信、チェックを外せば停止。
- **誰に出すかはサーバー側で判定**：拡張機能は Chrome にログイン中の Google アカウント（メールアドレス）を伝え、自分宛の通知だけを受け取ります。

| フォルダ | 内容 |
| --- | --- |
| `apps-script/` | スプレッドシートに貼り付ける Apps Script（`Code.gs`） |
| `extension/` | Chrome拡張機能（Manifest V3）。このフォルダをZIPにして公開します |
| `tests/` | 開発用テスト（納品物の動作には不要） |

---

## 導入手順（初回のみ）

作業はすべてお客様の Google Workspace アカウントで行います。

### 1. 通知管理スプレッドシートを作る

1. 本部の管理用アカウントで Google スプレッドシートを新規作成（例：「重要通知管理」）。
2. メニュー「拡張機能」→「Apps Script」を開き、`apps-script/Code.gs` の内容をすべて貼り付けて保存。
3. スプレッドシートを再読み込みし、メニュー「通知管理」→「初期セットアップ（シート作成）」を実行（初回は権限の承認が必要）。
   → 「通知」「宛先マスタ」「確認ログ」の3シートが作成されます。
4. スプレッドシートの共有は**本部の担当者だけ**にしてください（先生に共有する必要はありません）。

### 2. ウェブアプリとして公開する

1. Apps Script エディタ右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
2. 次のように設定してデプロイ。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. スプレッドシートのメニュー「通知管理」→「配布用の設定（ポリシーJSON）を表示」を開き、表示された JSON を控えます（手順4で使用）。

> `Code.gs` を後から修正した場合は「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」で更新してください（URLは変わりません）。

### 3. 拡張機能を Chrome ウェブストアに限定公開する

1. `extension` フォルダの**中身**を ZIP 圧縮（`manifest.json` が ZIP の最上位に来るように）。
2. お客様ドメインのアカウントで [Chrome ウェブストア デベロッパー ダッシュボード](https://chrome.google.com/webstore/devconsole) に登録し、ZIP をアップロード。
3. 公開範囲を「**限定公開**（自ドメインのユーザーのみ）」にして申請・公開。
4. 発行された**拡張機能ID**（32文字）を控えます。

### 4. Google 管理コンソールから一括配布する

1. [管理コンソール](https://admin.google.com) →「デバイス」→「Chrome」→「アプリと拡張機能」→「ユーザーとブラウザ」。
2. 配布対象の組織部門（園長・担当者が所属する部門）を選び、「＋」→「Chrome ウェブストアから追加（IDを指定）」で手順3のIDを追加。
3. インストール ポリシーを「**自動インストールする**」に設定。
4. 同じ画面の「拡張機能のポリシー」欄に、手順2で控えた JSON を貼り付けて保存。

```json
{
  "apiUrl": { "Value": "https://script.google.com/macros/s/xxxxxxxx/exec" },
  "apiKey": { "Value": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" }
}
```

先生側の操作は不要です。Chrome に園の Google アカウントでログインしていれば、自動で拡張機能が入り通知が届きます。
ツールバーの拡張機能アイコンをクリックすると、接続状態（正常／エラー、アカウント、所属園）を確認できます。

「園別」配信に使います。兼務はカンマ区切り。異動・退職時はここを直すだけです。

### 通知シート（1行＝1通知）

| 列 | 説明 |
| --- | --- |
| ID | 自動採番（触らない） |
| 有効 | チェックした行だけ配信。外せば即停止 |
| タイトル / 本文 / リンクURL | ポップアップの内容。リンクURLは任意（「詳細を開く」ボタン） |
| 対象種別 | `全園`（拡張機能が入っている全員）／`園別`／`個人別` |
| 対象 | 園別＝園名、個人別＝メールアドレス（どちらもカンマ区切りで複数可） |
| 開始日時 | 最初に表示する日時（必須） |
| 終了日時 | 任意。過ぎたら表示しない |
| 繰り返し単位・間隔 | `繰り返しなし`／`分`／`時間`／`日`／`週`／`月` と数値の組み合わせ |
| 曜日指定 | 任意。例 `月,火,水,木,金` |
| 未確認時の再表示(分) | 任意。「確認しました」を押さずに閉じたら、N分後に再表示 |

設定例：

| やりたいこと | 開始日時 | 単位 | 間隔 | 曜日指定 |
| --- | --- | --- | --- | --- |
| 4/1 9:00 に1回だけ | 2026/04/01 09:00 | 繰り返しなし | | |
| 毎日 9:00 | 2026/04/01 09:00 | 日 | 1 | |
| 平日だけ毎朝 8:30 | 2026/04/01 08:30 | 日 | 1 | 月,火,水,木,金 |
| 毎週月曜 9:00 | 2026/04/06 09:00（月曜） | 週 | 1 | |
| 毎月25日 10:00 | 2026/04/25 10:00 | 月 | 1 | |
| 30分おきにしつこく | 2026/04/01 09:00 | 分 | 30 | |

### 表示のルール

- 開始日時（繰り返しの場合は各回の予定時刻）になると、ポップアップウィンドウが最前面に開きます。
- 予定時刻に PC や Chrome が起動していなかった場合は、**次に Chrome を起動したとき**に表示されます（繰り返しの場合は直近の1回分のみ）。
- 「確認しました」を押すと、その回は再表示されず、「確認ログ」シートに日時・氏名・園名が記録されます。
- 終了日時が空欄の場合：繰り返しなし→開始から7日間有効、繰り返しあり→無期限。
- シートの変更は最大で約5分後（取得間隔）に各 Chrome へ反映されます。
- 同じ通知をもう一度全員に出したいときは、開始日時を新しい日時に書き換えてください。

## 知っておいていただきたいこと

- **Chrome が起動している間だけ**表示できます（拡張機能の仕組み上、Chrome 終了中は表示できません）。
- 宛先の判定は「Chrome プロファイルにログインしている Google アカウント」で行います。Chrome に園のアカウントでログイン（同期のオン／オフは問いません）している必要があります。
- 確認済みの記録は PC ごとに保持します。同じ先生が複数の PC を使う場合は、それぞれの PC で1回ずつ表示されます。
- **セキュリティ**：ウェブアプリは APIキー（ポリシーで配布）を知っている端末からのみ応答します。キーが漏れた場合はメニュー「通知管理」→「APIキーを再発行」→ 管理コンソールの JSON を更新、で無効化できます。機密性の高い内容は本文に書かず、リンク先（閲覧権限のある Google ドキュメント等）に置く運用を推奨します。
- 手順2で「全員」が選べない場合（組織外共有を制限している Workspace）は、「**（組織名）内の全員**」でデプロイし、ポリシー JSON に `"useGoogleLogin": { "Value": true }` を追加してください。この場合は Google ログイン情報で本人確認を行います。
- 取得間隔は `"pollMinutes": { "Value": 10 }` のようにポリシーで変更できます（既定5分）。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| アイコンの状態が「通知サーバーが未設定」 | 管理コンソールのポリシー JSON が保存されているか。`chrome://policy` で再読み込み |
| 「APIキーが正しくありません」 | キー再発行後に JSON を更新したか |
| 「サーバーの応答を読み取れません」 | apiUrl が `/exec` で終わるか、デプロイのアクセス設定が「全員」か |
| 特定の先生に届かない | 宛先マスタのメールアドレス・園名の表記（全角/半角・空白）が通知シートと一致しているか、「有効」にチェックがあるか |

## 開発者向け

```bash
TZ=Asia/Tokyo node --test tests/schedule.test.mjs
```

```bash
node tests/e2e.mjs
```

`tests/e2e.mjs` は Playwright（Chromium）で拡張機能を読み込み、模擬サーバーに対して「表示→確認→ログ送信→再表示」を検証します。
管理コンソールなしで手元確認する場合は、`chrome://extensions` で `extension` フォルダを読み込み、アイコン →「動作確認用の手動設定」に URL とキーを入力してください。
