# コピー履歴 & 保管庫(Chrome拡張機能)

PCでコピーしたテキストを自動で記録し、あとからコピーし直せる拡張機能です。

- **履歴**:直近100件を自動で記録。101件目からは古いものから消えます。
- **保管庫**:ずっと残したいテキストの置き場。自動では消えません。
- 履歴の各項目にある **「★ 保管」ボタン** で保管庫に保存できます。
- 上部のタブで「履歴」と「保管庫」を切り替えます。
- 項目をクリックするとクリップボードにコピーされます。
- 検索、個別削除、履歴の全削除、記録の一時停止ができます。

## インストール方法

1. このフォルダ(`clipboard-history-extension`)をPCにダウンロードする
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ
5. ツールバーの拡張機能アイコン(パズルのマーク)からピン留めすると使いやすくなります

## 注意点

- Chromeが起動している間だけ記録されます(Chrome以外のアプリでコピーしたテキストも約1秒おきの監視で拾います)。
- 記録されるのはテキストだけです(画像やファイルは対象外)。
- データはこのPCのChrome内にだけ保存され、外部には送信されません。
- パスワードなどをコピーした場合も履歴に残ります。必要に応じて「記録を一時停止」や個別削除を使ってください。
- 拡張機能を削除すると、履歴と保管庫のデータも消えます。
