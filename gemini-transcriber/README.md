# Gemini リアルタイム文字起こし（Chrome 拡張機能）

マイクの音声を Gemini の文字起こし専用モデル（Gemini 3.5 Transcribe Live）でリアルタイムに文字起こしし、続けて最新の Gemini Flash で「文脈上たぶんこうだろう」という誤変換を自動修正する Chrome 拡張機能です。
話し終わるたびに 1 ブロックができ、ブロックごと／まとめてワンクリックでコピーできます。

## できること

- **リアルタイム文字起こし**：`gemini-3.5-transcribe-live`（Live API）に音声をストリーミング。話している途中から文字が出て、少し黙るとそのまとまりが 1 ブロックとして確定します
- **文字起こし方式は 3 種類から選択**（設定 → 文字起こしの方式）
  | 方式 | モデル | 特徴 |
  | --- | --- | --- |
  | リアルタイム（初期値） | `gemini-3.5-transcribe-live` | 話しながら文字が出る |
  | ブロック単位：専用モデル | `gemini-3.5-transcribe` | 黙った後にまとめて送信、1〜2 秒で表示 |
  | ブロック単位：汎用 Flash | `auto`（最新の Flash） | 指示文で文字起こし |
- **自動フォールバック**：リアルタイム／専用モデルで失敗したブロックは、自動で汎用 Flash に切り替えて文字起こしします（ブロックに「Flash」と表示）。接続が切れても自動で再接続し、話していた分を送り直します
- **文脈による自動校正**：文字起こし直後に、直前のブロックを文脈として最新の Gemini Flash（`auto`、現在は `gemini-3.8-flash`）がもう一度チェックし、同音異義語・聞き間違いなどを修正します
  - 修正箇所は黄色でハイライト（マウスを乗せると元の語と理由を表示）
  - 差分ボタンで原文との違いを確認、「原文に戻す」も可能
- **コピー**
  - 各ブロックの「コピー」ボタン
  - 下部の「すべてコピー」でまとめてコピー（区切りは改行／空行／スペース／なしから選択）
  - オプション：話し終わるたびに最新ブロックを自動でクリップボードへ（他のタブで作業中でも動きます）
- ブロックの手動編集・削除・再試行
- 用語集（固有名詞・専門用語）で表記を寄せる
- 内容はブラウザに保存されるので、パネルを閉じても消えません

## インストール

1. このフォルダ（`gemini-transcriber`）をパソコンに置く
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ `gemini-transcriber` フォルダを選択
5. ツールバーのパズルアイコンからピン留めしておくと便利です

## 初期設定（API キー）

1. [Google AI Studio](https://aistudio.google.com/apikey) で Gemini API キーを発行
2. 拡張機能のアイコンをクリック → サイドパネル右上の ⚙（設定）
3. 「Gemini API キー」に貼り付けて「接続テスト」→「接続OK」と出れば完了

キーはこのブラウザの `chrome.storage.local` にだけ保存され、Gemini API（`generativelanguage.googleapis.com`）以外には送信されません。

## 使い方

1. アイコンをクリックしてサイドパネルを開く
2. 「録音開始」を押す
   - 初回だけマイク許可用のタブが開きます。「許可」を押したらタブを閉じて、もう一度「録音開始」
3. 話す → 少し黙る（初期値 0.9 秒）→ ブロックができて「文字起こし中」→「文脈で校正中」→ 完了
4. 「コピー」または「すべてコピー」

サイドパネルを閉じると録音は止まります。右上の ↗ で別ウィンドウにも出せます。

## 設定項目

| 項目 | 内容 |
| --- | --- |
| 文字起こしの方式 | リアルタイム／専用モデル／汎用 Flash（上の表） |
| モデル | リアルタイム用 `gemini-3.5-transcribe-live`、専用 `gemini-3.5-transcribe`、汎用 Flash と校正用は `auto`（利用可能な最新の Flash を自動選択）。「接続テスト」後は一覧から選べ、選ばれたモデルも表示されます |
| 言語 | 日本語／英語／自動（専用モデルには `ja-JP` などの言語コードとして渡します） |
| フィラーや言い直しを除く | 専用モデルでは SMART モード（フィラー除去・言い直しの反映・軽い整形）、オフで VERBATIM（逐語） |
| 用語集 | 固有名詞・専門用語を 1 行に 1 つ。専用モデルの認識ヒント（custom vocabulary）と校正の両方で使われます |
| 自動校正 | オフにすると文字起こしだけ（速く・安く） |
| 参考にする直前のブロック数 | 校正時に文脈として渡す数 |
| 黙ったら区切る長さ | 短いほど細かいブロックに、長いほど大きなまとまりになります |
| マイク感度 | 声を拾わないときは上げる、雑音で区切られるときは下げる。録音中のメーターの縦線が発話判定のしきい値です |
| 1 ブロックの最大長 | 話し続けてもこの長さを超えたら次の小休止で区切ります |
| 自動コピー | 話し終わるたびにそのブロックをクリップボードへ |

## 仕組み

```
マイク → AudioWorklet（16kHz モノラル）→ 無音検出で発話の始まり／終わりを判定
  [リアルタイム] 発話中の音声を Live API（WebSocket）へ逐次送信
                 → 途中経過（interim）をその場で表示 → 黙ったら確定（final）
  [ブロック単位] 黙った時点で WAV にして送信（専用モデル or Flash）
→ 直前のブロックを文脈にして Gemini Flash へ（校正・JSON で返却）… 順番どおりに直列
→ 画面に表示（修正箇所ハイライト）→ コピー
```

- リアルタイムは発話の区切りをこちらで判定し（activityStart / activityEnd）、1 発話ずつ順番に送るので、結果が別のブロックに混ざりません
- Live API の接続には時間制限があるため、話していない間に自動でつなぎ直します

- 校正結果が原文から極端に変わった場合（要約や書き換えをしてしまった場合）は、安全のため原文を残します
- 一時的なエラー（429／5xx）は自動で再試行し、それでも失敗したブロックには「再試行」ボタンが出ます

## 注意

- Gemini API の利用料金はご自身のキーに対して発生します（文字起こし＋ブロックごとの校正 1 回）。校正は設定でオフにできます
- Gemini 3.5 Transcribe は 2026 年 11 月時点でプレビュー提供です。仕様変更などでリアルタイム接続できない場合は、自動でブロック単位（汎用 Flash）に切り替わります。録音中のステータス表示とブロックのラベル（Live / Transcribe / Flash）で、どの方式で文字起こしされたか確認できます
- 必要な Chrome：116 以降

## ファイル構成

```
manifest.json        拡張機能の定義（Manifest V3）
background.js        サイドパネルの起動、バックグラウンドでのコピー
panel.html/css/js    メイン画面（サイドパネル／別ウィンドウ共通）
permission.html/js   マイク許可用ページ
offscreen.html/js    フォーカスが無いときのクリップボード書き込み
lib/recorder.js      マイク取得と無音検出（発話の区切り・音声フレームの配信）
lib/live.js          リアルタイム文字起こし（Live API / WebSocket）
lib/audio-worklet.js 音声フレームの取り出し
lib/gemini.js        Gemini API（モデル自動選択・専用モデル／Flash での文字起こし・校正）
lib/diff.js          修正箇所の差分計算
lib/storage.js       設定と履歴の保存
lib/wav.js           WAV 変換
lib/clipboard.js     コピー処理
icons/               アイコン
```
