# こども園・保育園 シフト管理（Google Apps Script）

職員×日付の一覧で「誰が何時から何時までいるか」をひと目で確認し、配置基準と照合しながらシフトを作る Web アプリです。
Google Apps Script（GAS）のウェブアプリとして動き、入力内容は指定の Google スプレッドシートに保存されます。
タブレット（縦・横）を主に想定し、PC・スマホでも操作できます。

- `gas/` … Apps Script にそのまま入れるファイル一式（このフォルダだけで動きます）
- `preview/index.html` … ブラウザだけで動くプレビュー（データはブラウザ内に保存。動作確認・お客様への説明用）
- `tools/` … 開発用のスクリプト（プレビューの組み立て・自動テスト）

## できること（要件との対応）

| 要件 | この アプリでの実現方法 |
|---|---|
| 1. 基本画面 | 園の画面の「月」表示が、職員（行）×日付（列）の一覧。クラスごとにまとめて表示し、名前の列と日付の行は画面を動かしても固定。表示の大きさ（小・標準・大）を切り替えれば、より多くの行を一度に見渡せます。印刷すると A3 横 1 枚の勤務表になります。 |
| 2. 勤務時刻の表示 | すべてのマスに「07:00〜／15:45」のように出勤・退勤時刻を表示。色と「早・遅」などの略称は補助として添えるだけで、時刻は必ず表示します。週表示では「07:00〜15:45」と休憩時間・配置クラスも表示します。 |
| 3. 表示期間 | 「月・週・日」を切り替え。同じ勤務データを、月（全体の調整）・週（確認）・日（当日の配置：タイムライン）で表示します。土曜日も含みます（日曜・祝日・年末年始は休園日として細い灰色の列）。 |
| 4. 編集と承認 | だれでもマスをタップして入力・変更できます（入力者名を記録）。保存すると **変更中**（青い点線・「変」）→「承認依頼」で **承認待ち**（オレンジ枠・「待」）→ 園長・主任・本部のアカウントで「承認印」を押すと **確定**（✓）。差戻しもできます。確定済みの勤務を変えると、確定時の内容を「変更前」として残し、承認者が比べられます。 |
| 5. 園全体・クラスごとの配置確認 | 15 分ごとに、その時間にいる子どもの数（時間帯別在園率から見込み）と、その時間に**そのクラスに配置されている職員**（休憩中は除く）を比べます。月・週表示ではクラスの見出し行と「園全体の配置」行に日ごとの判定、日表示では 30 分ごとの「配置／必要」の表を表示します。時間帯で別のクラスへ応援に入る設定もできます。 |
| 6. 配置基準との照合 | 0歳 3:1、1・2歳 6:1、3歳 15:1、4・5歳 25:1（令和6年4月改正後）、常時 2 名以上、朝夕特例などを照合し、**充足（緑✓）・要確認（黄！）・不足（赤×）** で表示。「どのクラスの何時が何名不足か」を一覧で示します。 |
| 7. 園の画面と本部の画面 | 上部のタブで切り替え（URL でも `?page=hq` で本部画面を直接開けます）。本部画面では園ごとの充足率・不足/要確認の箇所数・承認状況・勤務時間をカードで比較し、日ごとの充足状況の比較表、不足箇所の一覧、勤務時間の比較表を表示します。 |
| 8. 保存・集計 | 「勤務データ」シートに 1 人 1 日 1 行で保存（日付・氏名・出勤・退勤・休憩・**実働時間**・状態・承認者など）。そのままピボットテーブルや給与計算に使えます。メニューの「勤務時間の集計」から月次集計シートの作成・CSV 出力もできます。 |
| 9. 動作環境 | GAS のウェブアプリ。画面幅に合わせて配置が変わり、タブレット（縦横）・PC・スマホで使えます。 |
| 10. デザイン | やわらかいクリーム色と丸みのある見出し、時刻は読みやすい UD フォント（等幅）。状態と判定は色だけでなく記号・文字でも区別します。 |
| 11. 勤務例 | 3 園（こども園 1・保育所 2）の先月・今月・来月分の勤務例を自動で用意。土曜出勤・振休・有休・研修を含み、「さくら＝おおむね充足」「ひまわり＝不足が多め」「たんぽぽ＝要確認が多め」と特徴を変えています。 |
| 12. 修正時の大原則 | `setup` は足りないシート・列を追加するだけで、既存の勤務データやマスタは消しません。列は見出し名で探すので、列の並べ替えや独自の列の追加もできます。デモデータを入れ直すのは「デモデータを作り直す」を明示的に実行したときだけです。 |

## セットアップ（はじめての方向け・約 10 分）

### 1. スプレッドシートから Apps Script を開く
1. 保存先にしたい Google スプレッドシートを開きます（新しく作る場合は空のスプレッドシートを作成）。
2. メニュー「拡張機能」→「Apps Script」を開きます。

### 2. ファイルを貼り付ける
Apps Script エディタで、`gas/` フォルダの各ファイルと同じ名前のファイルを作り、中身をそのまま貼り付けます。

| 種類 | ファイル名（エディタでの名前） | 中身 |
|---|---|---|
| スクリプト | `Code`（最初からある `コード.gs` を置き換えても可） | `gas/Code.gs` |
| スクリプト | `Store` | `gas/Store.gs` |
| スクリプト | `Shared` | `gas/Shared.gs` |
| HTML | `Index` | `gas/Index.html` |
| HTML | `Styles` | `gas/Styles.html` |
| HTML | `App` | `gas/App.html` |
| HTML | `SharedJs` | `gas/SharedJs.html` |

- 「＋」→「スクリプト」／「HTML」で追加します。名前に `.gs` / `.html` は付けません。
- `appsscript.json`：左の「プロジェクトの設定（歯車）」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック → 表示された `appsscript.json` を `gas/appsscript.json` の内容に置き換えます（タイムゾーンが Asia/Tokyo になります）。

### 3. 初期設定を実行する
1. エディタ上部の関数の選択で `setup` を選び「▶ 実行」。
2. 初回は権限の確認が出ます。「権限を確認」→ 自分のアカウント →（「このアプリは Google で確認されていません」と出たら「詳細」→「〜（安全ではないページ）に移動」）→「許可」。
3. スプレッドシートに「勤務データ」「職員」「クラス」などのシートと、デモ用の勤務例が作られます。

### 4. ウェブアプリとして公開する
1. 右上「デプロイ」→「新しいデプロイ」→ 種類の選択（歯車）で「ウェブアプリ」。
2. 「次のユーザーとして実行」：**自分**
3. 「アクセスできるユーザー」：
   - Google Workspace（法人・園のドメイン）なら「（組織名）内の全員」がおすすめ
   - 個人の Google アカウントで試す場合は「Google アカウントを持つ全員」
4. 「デプロイ」→ 表示された **ウェブアプリの URL** を開きます。
   - 本部画面を直接開く URL：`（ウェブアプリのURL）?page=hq`
   - 園を指定して開く URL：`（ウェブアプリのURL）?en=E02`
   - タブレットでは、ブラウザの「ホーム画面に追加」でアプリのように開けます。

> コードを貼り替えたときは「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」で反映されます（URL は変わりません）。

### 別のスプレッドシートに保存したい場合
スタンドアロンの Apps Script から使う場合や、保存先を変えたい場合は、`Code.gs` 先頭の
`var SPREADSHEET_ID = '';` にスプレッドシートの ID（URL の `/d/` と `/edit` の間）を入れてから `setup` を実行します。

### clasp を使う場合（開発者向け）
```bash
npm install -g @google/clasp
```
```bash
clasp login
```
`.clasp.json` を作り `{"scriptId":"（スクリプトID）","rootDir":"gas"}` と書いてから:
```bash
clasp push
```

## 使い方

### 園の画面
- **月／週／日** をボタンで切り替え。◀ ▶ で前後、「今日」で今日へ。日付の見出しや判定の記号を押すと、その日の「日表示」に移ります。
- **マスを押す** → 勤務区分（早番・日勤・遅番・休み・有休など）を押すと時刻が入ります。時刻は −／＋（15 分）や一覧で変更。休憩・配置クラス・時間帯ごとの応援・備考も入力できます。
- **かんたん入力**：下に出る勤務区分を選び、マスを次々に押すだけで入力できます（月の勤務表をまとめて作るとき向け）。
- **承認依頼**：「変更中」の勤務をまとめて「承認待ち」にします。
- **承認印**：園長・主任・本部のアカウントでログインして押します。変更前と変更後を見比べて、まとめて確定または差戻しできます。
- **メニュー**：勤務時間の集計（CSV・月次集計シート）、配置基準と判定のしくみ、変更履歴、印刷、表示の大きさ、最新の内容に更新。
- 他のタブレットで入力された内容は 3 分ごとに自動で取り込みます（「設定」シートで変更可）。同じ勤務を同時に変えた場合は、後から保存した側に「他の人が先に変更しました」と表示し、上書きしません。

### 本部の画面
- 園ごとのカード：充足率（15 分ごとの判定のうち充足の割合）、不足・要確認の箇所数、不足のある日数、承認状況、実働時間・出勤延べ日数・土曜出勤・有休。
- 日ごとの充足状況：園×日付の比較表。▸ でクラスごとに展開、セルを押すとその日の不足箇所を表示し、そのまま園の日表示を開けます。日表示では各園の 30 分ごとの配置表を並べて比較できます。
- 不足・要確認の一覧（園・種類で絞り込み）と、勤務時間の比較表。

### デモ用アカウント（承認印を押せる人）
| アカウント | 権限 | 暗証番号 |
|---|---|---|
| 本部 管理者 | 本部（全園） | 0000 |
| 森田 恵子（園長） | さくらこども園 | 1111 |
| 佐藤 由美（主任） | さくらこども園 | 1112 |
| 岡本 洋子（園長） | ひまわり保育園 | 2221 |
| 松田 美香（主任） | ひまわり保育園 | 2222 |
| 青木 智子（園長） | たんぽぽ保育園 | 3331 |

**本番で使う前に**「アカウント」シートの暗証番号を変更し、「設定」シートの `demoMode` を `FALSE` にしてください（ログイン画面のデモ用暗証番号の表示が消えます）。
暗証番号は `sha256:（ハッシュ値）` の形でも保存できます。Google Workspace をお使いなら「メール」列に Google アカウントのメールを入れると、その人は暗証番号なしで承認者として認識されます。

## 配置基準と判定のしくみ

| 年齢 | 職員 1 人あたり | 備考 |
|---|---|---|
| 0歳 | 3人 | |
| 1・2歳 | 6人 | 1歳児配置改善加算（令和7年度〜）で 5:1 運用する場合は「配置基準」シートで 5 に |
| 3歳 | 15人 | 令和6年4月改正（20→15）。経過措置で当分の間 20 も可 |
| 4・5歳 | 25人 | 令和6年4月改正（30→25）。経過措置で当分の間 30 も可 |

- **園全体**（開所〜閉所）：その時間の子どもの数を年齢区分ごとに基準で割り、小数点第 1 位まで（第 2 位以下切り捨て）を合計して四捨五入。子どもがいる間は常に **2 名以上**（保育所一につき 2 人を下ることはできない）。
- **クラスごと**（クラス別保育の時間。園ごとに設定、土曜は合同保育として園全体のみ）：クラスの子どもの数から必要人数（切り上げ・最低 1 名）を出し、その時間にそのクラスに配置された職員（休憩中を除く）と比べます。
- 数えるのは「保育に従事（配置に数える）」職員だけ。調理・事務・研修中は数えません。
- **充足**：有資格者だけで必要人数を満たす
- **要確認**：人数は足りるが有資格者だけでは足りない（補助者・子育て支援員で補っている）。朝夕の「2 名のうち 1 名は子育て支援員等で可」特例（必要数の合計が 1.4 以下）や、有資格者が必要数の 3 分の 2 以上いる場合
- **不足**：人数が足りない、または有資格者が必要数の 3 分の 2 未満

基準の値・特例のしきい値・開所時間・クラス別保育の時間・時間帯別在園率は、すべてスプレッドシートで変更できます。
配置基準・特例の扱いは自治体ごとに条例・通知で異なる場合があります。園の所在地の基準を必ず確認してください（この判定は勤務表の確認を助ける目安です）。

## スプレッドシートの構成

| シート | 内容 |
|---|---|
| 勤務データ | 1 人 1 日 1 行。勤務ID・園・日付・曜日・職員ID・氏名・勤務区分・種類（勤務/休み/有休/研修）・出勤・退勤・休憩開始・休憩(分)・拘束時間(h)・**実働時間(h)**・配置クラス・時間帯別の配置・状態（変更中/承認待ち/確定）・入力者・入力日時・承認者・承認日時・変更前（確定時の内容）・備考 |
| 職員 | 氏名・職種・資格・有資格として数える・保育に従事（配置に数える）・雇用形態・主担当クラス・週所定時間・在籍 |
| クラス | クラス名・年齢・0〜5 歳児数（異年齢クラスも可） |
| 園 | 開所・閉所（平日/土曜）・クラス別保育の時間・休憩中を配置に数えるか・臨時休園日 |
| 勤務区分 | 早番・日勤などのパターン（時刻・休憩・色）。園ごとに上書き可 |
| 配置基準 | 年齢ごとの「職員 1 人あたりの子どもの数」 |
| 時間帯別在園率 | 時刻ごとの在園率（平日/土曜）。子どもの数の見込みに使います |
| アカウント | 承認できる人（本部・園長・主任）と暗証番号 |
| 設定 | 法人名・デモモード・本部画面のログイン要否・最低人数・特例のしきい値・自動更新の間隔 |
| 変更履歴 | だれがいつ何を変えたか（入力・変更・削除・承認依頼・承認・差戻し） |
| 月次集計 | 「勤務時間の集計」→「スプレッドシートに月次集計を作成」で作られる、職員ごとの月合計 |

- 日付・時刻は「2026-11-13」「07:30」の文字列で保存しています（自動変換によるずれを防ぐため）。計算に使う場合は `DATEVALUE()` / `TIMEVALUE()` が使えます。
- 「誰が、いつ、何時間働いたか」は「勤務データ」の **氏名・日付・実働時間(h)** の 3 列で集計できます（ピボットテーブル：行＝氏名、値＝実働時間の合計、フィルタ＝日付・状態＝確定）。
- 職員・クラス・勤務区分の追加や変更は、それぞれのシートに行を足すだけで画面に反映されます（ID は重複しないように）。

## 注意・制限
- 1 人 1 日 1 勤務です（同じ日に 2 回に分かれた勤務は、時間帯別の配置で表すか、備考で補ってください）。日をまたぐ夜勤には対応していません。
- 勤務データが数万行になると表示が遅くなります。年度が変わったら「勤務データ」シートをコピーして保管し、古い行を削除してください。
- 「次のユーザーとして実行：自分」で公開するため、スプレッドシートは公開した人の権限で読み書きされます。職員にスプレッドシート自体を共有する必要はありません。
- 子どもの数は在園率からの見込みです。実際の登降園の人数とは異なる場合があります。

## 開発者向け
Node.js 18 以上で、`shift-manager` フォルダで実行します。

- プレビューの組み立て（`gas/Shared.gs` を変えたら必ず実行。`gas/SharedJs.html` も作り直されます）
  ```bash
  node tools/build.mjs
  ```
- サーバー側（Code.gs / Store.gs）を擬似スプレッドシートで動かすテスト
  ```bash
  TZ=Asia/Tokyo node tools/gas-sim.mjs
  ```
- 画面の自動操作テスト（Playwright。スクリーンショットを `preview/` に保存）
  ```bash
  node tools/smoke.mjs
  ```
- デモデータの不足・要確認の出方を確認
  ```bash
  node tools/simulate.mjs 2026-11-13
  ```

修正するときは、既存の勤務例・時刻の表示・一覧性を保ったまま、依頼された部分だけを変えてください（`setup` は既存データを消しません。デモデータを入れ直すのは `resetDemoData` を実行したときだけです）。
