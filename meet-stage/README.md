# Meet Stage

Google Meet でお客様に見せる画面を、**操作用の別ウィンドウ** からワンクリックで切り替える Chrome 拡張機能です。
自分は好きなタブやアプリを見たまま、お客様には選んだ画面だけが映ります。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこの `meet-stage` フォルダを選ぶ
   (zip で受け取った場合は、先に展開してからそのフォルダを選ぶ)
4. 以前の版を入れていた場合は、古いほうを削除する
5. すでに開いている Meet のタブは一度再読み込みする

## 使い方

1. Meet の会議に参加する
2. ツールバーの Meet Stage アイコンをクリックすると、操作用ウィンドウが開く
3. **「+ 追加」** を押し、Chrome の選択ダイアログで見せたいもの(タブ / ウィンドウ / 画面全体)を選ぶ。
   見せる可能性があるものを会議前にすべて追加しておく
   - PowerPoint など Chrome 以外のアプリは「ウィンドウ」から選べます
   - デスクトップ全体は「画面全体」から選べます
4. 一覧のソースをクリックすると、それがお客様に映る(最初のクリックで画面共有が始まる)
5. 別のソースをクリックすると、共有を止めずに映る画面が切り替わる
6. 「共有を停止」で画面共有を終える。登録したソースは残るので、またクリックすれば再開できる

一覧にはサムネイルが出ます。「名前」で分かりやすい名前に変更、「削除」で登録を解除できます。

## 制限

- 開いているウィンドウを自動で一覧にすることは Chrome 拡張機能ではできません。
  「+ 追加」で1つずつ選ぶ必要があります(選ぶのは最初の1回だけ)
- 登録したソースは Meet のタブの中で保持しています。Meet のタブを再読み込み・閉じると登録は消えます
- 最小化したウィンドウは映像が止まることがあります。最小化せず背面に置いてください
- 音声(タブの音など)は共有されません
- Meet の画面に手を入れる方式のため、Meet 側の変更で動かなくなる可能性があります
