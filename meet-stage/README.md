# Meet Stage

Google Meet の画面共有や HDMI 投影でもたつかないよう、**見せる画面(投影ウィンドウ)** と **操作用サイドバー** を分ける Chrome 拡張機能です。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこの `meet-stage` フォルダを選ぶ
   (zip で受け取った場合は、先に展開してからそのフォルダを選ぶ)
4. ツールバーの Meet Stage アイコンをクリックするとサイドバーが開く

## 使い方

1. サイドバーの **「投影ウィンドウを開く」** を押す
   - 外部ディスプレイ(HDMI など)がつながっていれば、そちらに全画面で開きます
   - なければ通常のウィンドウとして開きます
2. **「その他のタブ」** の一覧からタブをクリックすると、そのタブが投影ウィンドウに映ります
3. **「映す画面」** の一覧をクリックすると、映すタブがワンクリックで切り替わります
   - 「待機画面(黒)」で一時的に何も見せない状態にできます
   - 「戻す」でタブを元のウィンドウに戻せます
4. PowerPoint など **Chrome 以外のアプリ** を映すときは **「+ アプリのウィンドウ / 画面を追加」** を押し、
   選択ダイアログで対象のウィンドウ(または画面全体)を選びます。会議前に必要な分だけ追加しておけば、
   以降は一覧のクリックだけで切り替わります
   - 一覧にはサムネイルが出ます。「削除」でキャプチャを終了します
   - 映像はサイドバーが保持しているため、**サイドバーを閉じるとキャプチャは終了します**
   - 操作(スライド送りなど)は元のアプリ側で行います
5. Meet で共有するときは **「画面共有を開始」** を押し、Chrome の選択ダイアログで
   「ウィンドウ」→「Meet Stage 投影ウィンドウ」を選びます(最初の1回だけ)。
   以降の切り替えはサイドバーのクリックだけで、選択ダイアログは出ません

## 制限

- 共有開始時の Chrome の選択ダイアログは、ブラウザのセキュリティ上スキップできません
- 他アプリのウィンドウは追加するたびに1回、Chrome の選択ダイアログで選ぶ必要があります
- 最小化したウィンドウは映像が止まることがあります(OS の仕様)。最小化せず背面に置いてください
- 「画面共有を開始 / 共有を停止」は Meet 画面上のボタンを探して押す方式のため、Meet の画面変更で動かなくなる可能性があります
